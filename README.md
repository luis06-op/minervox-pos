# ⛏️ MINERVOX - Gestión & Suministros Mineros

MINERVOX es una aplicación web (PWA) de Punto de Venta (POS) y gestión de inventario, diseñada específicamente para comercializadoras de insumos y reactivos químicos de minería. 

El sistema optimiza el control de stock, la generación de comprobantes en PDF (facturas y vales de crédito) y la gestión de cartera ("fiaos") de manera ágil y adaptada a dispositivos móviles.

## 🚀 Características Principales

*   **Punto de Venta Dinámico:** Facturación rápida con cálculo automático de precios diferenciados (Contado vs. Crédito).
*   **Gestión de Cartera Inteligente:** Control de cuentas por cobrar con alertas visuales de vencimiento (Semáforo de deudas).
*   **Generador de Pagarés:** Emisión automática de vales de entrega en PDF listos para imprimir o compartir por WhatsApp.
*   **Buscador Autocompletable de Clientes:** Búsqueda en tiempo real por Cédula/NIT para agilizar las ventas en mostrador.
*   **Control de Inventario:** Alertas de reabastecimiento para productos críticos (ej. Cianuro, Zinc, Ácido).

## 🛠️ Tecnologías Utilizadas (Stack)

*   **Frontend:** HTML5, CSS3 (Tailwind CSS), JavaScript Vanilla / Vue.js
*   **Backend:** PHP 8+ (Arquitectura PDO)
*   **Base de Datos:** MySQL / MariaDB
*   **Librerías Adicionales:** pdf, jsPDF, FPDF
