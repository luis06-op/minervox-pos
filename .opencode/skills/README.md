# Habilidades del proyecto

Guías de trabajo para el asistente. **No son código de MINERVOX**: no se cargan
en el navegador ni se ejecutan en producción.

Se copiaron del repositorio **ForestID_V2** (rama `diseno-amarillo-sol`,
carpeta `.opencode/skills`), que es del mismo dueño, porque sirven para este
proyecto:

| Habilidad | Para qué se usa aquí |
|---|---|
| `frontend-design` | Criterio de diseño para el POS y los reportes: botones grandes, colores del negocio, nada de interfaces genéricas. |
| `skill-creator` | Cómo escribir una habilidad nueva (por ejemplo, una específica de MINERVOX). |
| `doc-coauthoring` | Guía para redactar documentación, propuestas y especificaciones. |

Los scripts en Python de `skill-creator/scripts/` son **material de referencia**:
este proyecto es PHP + HTML sin Node ni Python en producción, así que no se
ejecutan. Cada carpeta conserva su `LICENSE.txt`.
